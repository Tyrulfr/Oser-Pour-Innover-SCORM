# Bibliothèque d’icônes et d’objets — Oser pour innover

Dossier de **conception** (hors paquets SCORM). Tous les fichiers sont des **PNG RGBA**.

Les icônes déjà utilisées en incrustation restent aussi dans `modules/_shared/icones/` pour le runtime. Ici, c’est la **bibliothèque unique** à réutiliser (motion, supports, incrustations, fascicules).
