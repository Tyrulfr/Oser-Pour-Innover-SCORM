# Transcripts — fichiers de création

Espace de travail pour les transcriptions (et scripts) des vidéos témoin et expert.

Ces fichiers **ne vont pas dans les paquets SCORM** (`build.sh` ne zippe que `modules/`) et **ne sont pas liés depuis le site**. Ils restent dans le dépôt pour rédiger les quiz et questionnaires.

## Dépôt

- `temoins/` — T1.docx … T13.docx (13/13)
- `experts/` — E{n}_{Prénom}.docx

Présents : E1, E3, E5–E14, E16–E24 (sauf E15).

Manquants : E2, E4, E15.
